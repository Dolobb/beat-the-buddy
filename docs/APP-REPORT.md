# Мини-апп: реализация и приёмка

Дата: 10 ноября 2026. Источник требований: `SPEC-APP.md`, прочитан целиком перед исходниками.

Код мини-аппа реализован. Автоматические проверки проходят. Приёмка через настоящий HTTP-порт и браузер
в этой среде заблокирована; эти пункты не считаются пройденными.

## Сделано

- `config.ts`: отдельные 12 видов оружия, HP/KO, костюмы f1/f3; старые экспорты сохранены.
- `appstate.ts`: чистое состояние, подпись Telegram HMAC и timingSafeEqual, срок 24 часа, DEV,
  дельты, идемпотентный seq, покупки, перенос базы виджета с маской 3, два рейтинга.
- `server.ts`: Node HTTP без зависимостей, loopback, `/buddy/` и корень, локальная статика с MIME/cache,
  защита путей и symlink, JSON-ошибки, тело до 4 КБ, атомарный tmp+rename, debounce 1 с, сброс при сигналах.
- Клиент: локальные Matter/Telegram SDK, предзагрузка всех 21 PNG из манифеста, canvas с DPR/resize,
  рэгдолл из 10 тел, податливые суставы, стабилизация, захват/бросок, столкновения с cooldown/cap15,
  KO и восстановление через 2.5 секунды.
- Все kinds оружия: hand, melee, throw, gun с автоогнём и проверкой луча, bomb по fuse/контакту,
  drop с тяжёлым телом. Снаряды ограничены временем жизни.
- HUD, анимированные монеты, здоровье, 6 друзей, костюмы, два рейтинга с выделением себя,
  магазин с подтверждением вторым тапом, сохранение выбора и mute.
- Комбо ×1…×3, бонус KO, синяки/пластыри и крестики при отсутствии вариантов голов,
  звёзды, покраснение, фразы, hit-stop, частицы с пулом 200, тряска, взрывы, дым,
  трассеры/вспышки/гильзы, WebAudio-синтез с лимитом 12 голосов и haptics.
- Сеть: сохранённая очередь по друзьям, неизменяемый повтор пакета, сверка seq после перезагрузки,
  разделение пакетов до 2000 ударов, один запрос одновременно, отправка через 5 секунд/покупку/hidden,
  keepalive для фоновой отправки, офлайн-плашка и предупреждение при недоступном localStorage.
- `npm run app`, systemd/nginx, инструкции rsync/BotFather и раздел README.

## Приёмка из SPEC-APP.md

### 1. `npm test` — пройдено

```text
tests 42
pass 42
fail 0
cancelled 0
skipped 0
```

Включены все старые тесты виджета. Новые проверки: подпись/подделка/просрочка,
валидация и накрутка, покупка, миграция/top, потеря ответа/повтор/reload очереди,
физика и все kinds, пул эффектов, соответствие PNG манифесту и относительные URL.

`main.test.js` исполняет настоящие модули игры в VM с подменёнными DOM/Canvas/API;
проверяет загрузку, DPR, отмену ввода, KO/бонус/респаун и костюмы. Это логическая проверка, не визуальная.

### 2. Запуск + curl — заблокировано средой

Выполнен запуск:

```sh
DEV=1 PORT=8791 node server.ts &
```

Фактический вывод:

```text
zsh:1: nice(5) failed: operation not permitted
Server error: listen EPERM: operation not permitted 127.0.0.1:8791
server exit: 1
```

Затем выполнены GET `/buddy/`, `/buddy/api/config`, `/buddy/api/top`
и два одинаковых POST `/buddy/api/sync` с телом:

```json
{"initData":"","seq":1,"f":0,"hits":3,"coins":6}
```

Каждый из пяти curl завершился кодом 7:

```text
curl: (7) Failed to connect to 127.0.0.1 port 8791 after 0 ms: Couldn't connect to server
```

Процесс сервера сам завершился с кодом 1; работающего процесса для остановки нет.
Временная миграционная копия `appdata.json`, созданная до отказа listen, удалена после проверки,
что все seq остались нулевыми. Исходный `data.json` не изменялся нашим кодом;
параллельно работающий виджет продолжал обновлять свой прогресс.

Дополнительная проверка `node --test server.test.ts` — 4/4:
настоящий обработчик сервера вызван без открытия сокета, с изолированной временной базой.
Проверены префикс/корень, HEAD/MIME/cache, пути, JSON/401/413, config/top,
нулевая синхронизация, два одинаковых seq и атомарный сброс при остановке.
Для тестового переноса с балансом 42 оба одинаковых POST возвращают:

```json
{"c":48,"w":3,"seq":1}
```

Это результат теста обработчика, **не ответ curl**. Полный HTTP-прогон нужно повторить
в среде, где разрешён listen на loopback.

### 5. URL и ассеты — пройдено

Перечитаны модули клиента. Собственные импорты, src и fetch используют `./...`;
обращений к внешним доменам в собственном клиентском коде нет. SDK подключён локально.
Для каждой головы и детали тела проверены наличие PNG и реальные размеры из PNG header
против `manifest.json`. Выбор костюма ограничен конфигом, hurt/ko имеют программный fallback.

Контрольные SHA до/после совпали у `bot.ts`, `state.ts`, `widget/widget.html`,
`scripts/build.ts`, `scripts/size.ts`, `app/assets/manifest.json`.
Готовые PNG/vendor не менялись. Веток, коммитов, установок зависимостей и внешних сетевых запросов не было.

## Исправления по проверке

- `requestFullscreen` вызывается только для Telegram >=8.0: SDK вне Telegram иначе бросает исключение.
  Регрессионный тест сначала падал на `WebAppMethodUnsupported`, после исправления проходит.
- Отмена pointer/blur/hidden и переключение управления не превращаются в тычок.
- Таймер KO использует null вместо 0: респаун работает и для нокаута в нулевой момент игрового времени.

Отдельный read-only review подтвердил баг fullscreen; других подтверждённых блокеров в очереди,
покупках и повторной отправке не нашёл.

## Упрощения и непроверенное

- Визуальная приёмка, звук, haptics, ощущение силы и 60 fps на телефоне не проверены.
  Chrome-инспектор завершился до запуска (`Chrome exited early, code null`).
  Computer Use не одобрил доступ к Google Chrome; визуального подтверждения нет.
- Реальный Telegram/initData, HTTPS/nginx, systemd и BotFather не проверялись и не настраивались.
- Сервер ограничивает награду по потолку с учётом ×3/столкновений/KO и 5% округления;
  серверной симуляции физики нет. Общий seq означает одну активную сессию на пользователя:
  одновременная игра с нескольких устройств может отклонять пакеты с совпавшими номерами.
- При hidden уже выполняющийся fetch нельзя задним числом превратить в keepalive;
  новые дельты остаются в localStorage и отправляются при возврате/следующем запуске.
- Detector интерфейса выдал одно предупреждение `cream-palette` для тёплой комнаты.
  Палитра оставлена как сознательный выбор для комнаты игры; это не подтверждение визуального качества.

Запуск вне ограниченной среды: `DEV=1 npm run app` → `http://127.0.0.1:8787/buddy/`.
