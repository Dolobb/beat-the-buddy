# Текстуры — главная задача сейчас

Головы и тела у нас уже нарисованы и выглядят сильно. Всё остальное пока сделано заглушками: оружие — emoji,
фон — цветная стена из кода. Картинки здесь дадут больше «вау», чем любая правка кода.

Порядок важности: **1 → 2 → 3**, остальное потом. Каждую задачу можно сдавать отдельным PR.

---

## Стиль: общие правила для всех картинок

Всё должно выглядеть так, будто нарисовано одной рукой с головами из `heads-src/`. Перед началом открой
`heads-src/f3.png` и `body-src/f3.png` и держи их перед глазами.

- **Плоский мультяшный вектор:** толстый тёмный контур, 4–6 сплошных цветов на объект, без градиентов,
  без теней, без текстур, без бликов.
- **Фон — сплошная маджента `#FF00FF`.** Скрипт вырезает её в прозрачность чисто, без ореолов.
  Прозрачный PNG генераторы часто рисуют с грязью по краям, поэтому маджента надёжнее.
  Исключение — фоны комнат (задача 2): там маджента не нужна.
- **Никакого текста** на картинках. Генераторы портят буквы, особенно кириллицу. Надписи рисует код.
- **Палитра интерфейса** для акцентов: чернила `#21140f`, бумага `#fff6e0`, желток `#ffcf1f`, кровь `#ff4530`, мята `#2fd39c`.
- **Новый вариант делай правкой готовой картинки,** а не с нуля. Прикладывай референс и пиши «same style, …».
  Так стиль не плывёт.

### Чем генерировать

Любым генератором, который принимает картинку-референс (головы и тела сделаны в ChatGPT, gpt-image).

- **Всегда прикладывай референс:** `heads-src/f3.png` или уже готовое оружие. Без него стиль будет другим.
- **Генерируй по 2–4 варианта** и выбирай лучший. Черновики клади в `out/` (она в `.gitignore`).
- **Проверяй фон пипеткой:** он должен быть ровно `#FF00FF`. Если там розовый с шумом, проси «flat solid magenta #FF00FF background, no gradient».

### Как сдавать

1. Исходник кладёшь в папку из задачи, имя строго по таблице.
2. `.venv/bin/python scripts/assets.py` пересобирает `app/assets/`. Для оружия и фонов скрипт надо дописать, это часть задачи.
3. `DEV=1 npm run app` и смотришь в браузере, лучше в мобильной эмуляции DevTools (iPhone 12–15).
4. `npm test`, затем PR со скриншотом «до/после».

### Что нарисовать

12 картинок, по одной на файл, **1024×1024, объект смотрит вправо** (ствол, боёк, носок тапка — вправо),

| `slipper.png` | Тапок 🩴 | резиновый шлёпанец-сланец, синий с белым |

### Промпт (по одному предмету)

К первому запросу приложи `heads-src/f3.png` как образец стиля. Дальше в том же чате прикладывай уже готовое оружие.

```
Use the attached image only as a STYLE reference: flat vector cartoon, thick
dark outline, 4-6 solid colors, no gradients, no shading, no texture, no
highlights.

Draw a single game item: <ОПИСАНИЕ ИЗ ТАБЛИЦЫ>. Exaggerated chunky cartoon
proportions, reads clearly at 64x64 pixels. Side view, pointing to the
RIGHT, centered, filling about 80% of a square frame.

Solid pure magenta #FF00FF background, nothing else in the frame, no text,
no hands holding it, no shadow. Square 1024x1024.
```

Для следующих: «Same style as the attached item. Now draw: <описание>. Same rules: pointing right, magenta background, no text».

### Как встроить в код (агент делает сам)

1. `config.ts`: добавить каждому элементу `appWeapons` поле `key` (`'hand'`, `'fist'`…). Порядок и цены не трогать.
2. `scripts/assets.py`: блок для `weapons-src/*.png` — вырезать мадженту, обрезать по содержимому, ужать до 256 px
   по большей стороне, сохранить `app/assets/weapon-<key>.png`, записать размеры в `manifest.weapons`.
3. `app/main.js`: картинки оружия маленькие, их грузить все сразу на старте вместе с текущим другом (`loadImages`).
4. Заменить emoji на картинку там, где есть файл, и оставить emoji запасным вариантом:
   - карточки магазина, около `main.js:179` — `<img>` вместо текста в `.icon`;
   - снаряды и падающие предметы, `weapons.js` около строки 176 (`fillText(weapon.icon…)`) — `drawImage`;
   - замах, `fx.swing` в `fx.js` — `drawImage` с поворотом;
   - ракета базуки — `rocket.png`, ядерка — `nuke-fall.png`.
5. Тест в `app/assets.test.js`: у каждого оружия с `key` есть файл в манифесте.

**Готово, когда** ни одного emoji в магазине и в полёте нет, оружие читается на телефоне, `npm test` зелёный.

## 2. Комнаты друзей

**Почему.** Фон занимает 70% экрана. Сейчас это цветная стена с растром и именем — аккуратно, но пусто.
У каждого друга должна быть своя комната, это сразу делает игру «про нас».

### Что нарисовать

6 фонов, **1080×1920 (вертикальный, 9:16)**, без персонажей и без маджента-фона.

- **Линия пола на 78% высоты** (около y = 1500). Ниже — пол, выше — стена. Код совместит эту линию с полом физики.
- **Центр кадра пустой:** там стоит персонаж. Детали интерьера — по краям и на стене.
- **Верхние 15% и нижние 22% спокойные,** без мелочей: там лежат полоска HP и магазин оружия.
- Стиль тот же плоский, но **приглушённее персонажа** (меньше контраста, светлее), чтобы друг читался поверх фона.

| Файл `rooms-src/` | Друг | Идея комнаты |
|---|---|---|
| `f1.png` | Пешка | шахматный клуб или комната с шахматной доской на стене, пешки на полке |
| `f2.png` | Бло | цирковая гримёрка: зеркало с лампочками, грим, на стене листки «ДОЛГ» (без читаемого текста — просто листки с цифрами-закорючками) |
| `f3.png` | Боб | комната общаги: двухъярусная кровать, гирлянда, худи на стуле |
| `f4.png` | Джстл | подъезд или гараж зимой: граффити-пятна, пуховик на крючке, наушники |
| `f5.png` | Мар | казарма: заправленная койка, плакат со звездой, сапоги |
| `f6.png` | Дрон | студия: микрофон, наушники на стойке, розы в вазе |

Темы — предложение. Если знаешь, что зайдёт пацанам лучше, рисуй своё, только сохрани правила по композиции.

### Промпт

```
Use the attached image only as a STYLE reference: flat vector cartoon, thick
dark outline, solid colors, no gradients, no photo textures.

Draw an EMPTY interior background for a mobile game, vertical 1080x1920.
Theme: <ТЕМА ИЗ ТАБЛИЦЫ>.

Composition rules:
- The floor line is a straight horizontal line at 78% of the image height.
  Wall above, floor below, flat front view, no perspective tricks.
- The center of the image is empty wall space: a character will stand there.
  Put furniture and props only near the left and right edges.
- Keep the top 15% and the bottom 22% calm and simple, UI covers them.
- Muted, lighter colors than a character would have, low contrast, so a
  bright cartoon character reads clearly in front of it.
- No people, no animals, no text, no letters, no numbers.
```

### Как встроить в код

1. `scripts/assets.py`: `rooms-src/<id>.png` → `app/assets/room-<id>.jpg` (качество ~80, ширина 1080), в `manifest.rooms`.
2. `buildRoom()` в `main.js`: если у друга есть комната, рисовать её режимом cover так, чтобы y = 78% картинки
   совпал с `floor`. Цвет шапки Telegram (`setHeaderColor`) брать по-прежнему от цвета друга.
   Без картинки работает старая стена.
3. Добавить комнату в `needs(i)`, чтобы она грузилась вместе с головой друга.
4. Проверить на узком (iPhone SE) и длинном (iPhone 15 Pro Max) экране: пол на месте, персонаж не тонет в фоне.

## 3. Одежда для остальных друзей

**Сейчас** одежда есть только у Пешки (`body-src/f1.png`) и Боба (`body-src/f3.png`), у остальных трусы.
Кнопка переодевания в правой панели у них неактивна.

### Что нарисовать

4 листа по 5 деталей, **1536×1024**, в `body-src/`:

| Файл | Друг | Одежда (по головам и характеру) |
|---|---|---|
| `f2.png` | Бло | клоунский комбинезон в крупный горох, большие пуговицы-помпоны, клоунские ботинки |
| `f4.png` | Джстл | чёрный пуховик, тёмные спортивки, массивные кроссовки |
| `f5.png` | Мар | оливковая армейская гимнастёрка с ремнём, галифе, сапоги |
| `f6.png` | Дрон | толстовка-оверсайз, широкие джинсы, кеды |

### Промпт

Обязательно прикладывай `body-src/f3.png` (лист Боба) — от него берутся пропорции и порядок деталей.

```
This is a sprite sheet of five separate ragdoll body parts. Redraw it with
a different outfit: <ОДЕЖДА ИЗ ТАБЛИЦЫ>. Top goes on the torso and both arm
parts, bottoms go on the thigh and lower leg, shoes on the lower leg.

Keep exactly: the same five parts in the same left-to-right order (torso,
upper arm, forearm with hand, thigh, lower leg with shoe), the same size,
position and proportions of every part, the same flat style with thick
dark outline and solid colors, the same peach skin tone, the same solid
magenta #FF00FF background. Parts must not touch, keep the wide gaps.
No head, no text, no shadows. 1536x1024.
```

**Проверь:** деталей ровно пять, между ними видна маджента, кисть и ступня на месте.
Если генератор слепил детали, допиши «parts must not touch, keep wide gaps».

### Как встроить

1. Положить лист в `body-src/<id>.png`.
2. В `config.ts` другу добавить `outfit: '<id>'` (как у `f1` и `f3`).
3. `.venv/bin/python scripts/assets.py` — скрипт сам нарежет детали.
4. В браузере: кнопка одежды у друга активна, суставы стыкуются, ничего не болтается отдельно.
