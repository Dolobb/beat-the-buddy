# Архитектура

## Общая схема

```
Telegram (телефон игрока)
   └─ Mini App: https://pisarenkovmax.ru/buddy/  ── статика (nginx, gzip, ETag, http2)
         │  GET  /buddy/api/config   друзья, оружие, фразы, HP, бонус KO, множитель монет
         │  POST /buddy/api/sync     пакет прогресса, подписан Telegram initData
         │  GET  /buddy/api/top      рейтинг
         ▼
nginx (reg.ru) ── /buddy/api/ → 127.0.0.1:8787
         ▼
server.ts (systemd unit `buddy`, /opt/buddy) ── appdata.json (атомарная запись tmp+rename)
```

Бота на сервере нет: reg.ru не достаёт до Telegram ни туда, ни обратно. Игра открывается прямой ссылкой Mini App,
которую выдал @BotFather. Подпись initData сервер проверяет сам, ходить в Telegram для этого не нужно.

Старый виджет (`bot.ts`, long polling) живёт отдельно на ноутбуке Максима и считает монеты в своей базе `data.json`.
Мини-апп при первом запуске перенёс оттуда монеты, дальше базы независимы.

## Клиент (`app/`)

ES-модули без сборщика. Matter.js 0.20 и Telegram SDK лежат в `app/vendor/`. Шрифты Dela Gothic One и Golos Text лежат
локально в `app/vendor/fonts/`.

### Цикл кадра (`main.js`)

1. Фиксированный шаг физики 1000/60 через аккумулятор. Во время замедления после KO (`slowUntil`) шаг растягивается.
2. Рендер на canvas: заранее нарисованная комната (`buildRoom`, отдельный холст), затем части тела в `drawOrder`,
   затем оружие и эффекты (`fx.draw`).
3. HUD живёт в HTML поверх canvas: полоска HP с «призраком», монеты, комбо, правая панель, карточки оружия.

### Урон и монеты (`damage()` в `main.js`)

```
multiplier = min(3, 1 + floor((combo - 1) / 5))          комбо: удар не позже 1,5 с после прошлого
coins      = (dealt * multiplier + (KO ? config.ko : 0)) * config.mult
```

Сейчас `ko = 50`, `mult = 2`, у друга 200 HP. При нокауте замедление, зум на голову, оверлей «НОКАУТ» и дождь монет.
Через 2,7 с друг поднимается с полным HP.

Сервер не симулирует игру. Он только ограничивает пакет: монет не больше, чем можно было выбить таким числом ударов
максимальным оружием с x3-комбо, KO и множителем (`appstate.ts`, `applySync`). Это защита от грубой накрутки, не античит.

### Физика (`physics.js`)

- Рэгдолл из 10 тел: голова, торс, по две руки (плечо, предплечье с кистью) и ноги (бедро, голень).
- Масштаб: `min(height * .64 / 860, width / 560)`. Персонаж стоит на полу.
- **Поза** держится пружинами к углам стойки. **«Кукловод»** (support) — констрейнт, который держит торс над полом.
- **Stagger:** после удара таймер ослабляет позу и «кукловода», тело улетает и потом встаёт обратно.
- `physics.impulse(body, point, velocity)` — импульс скоростью. Если вызван внутри шага (`collisionStart`),
  он откладывается в `pendingImpulses` до конца солвера.
- `physics.punch` — сплющивание части в момент удара (визуальное, не физическое).
- При KO подгибаются колени, тело оседает.

### Оружие (`weapons.js`, описание в `config.ts` `appWeapons`)

| kind | Как работает | Примеры |
|---|---|---|
| `hand` | хватаешь и швыряешь тело | Рука |
| `melee` | удар в точке тапа, радиус `radius` | Кулак, Бита |
| `throw` | снаряд летит из-за края экрана в точку | Тапок, Кирпич |
| `gun` | автоогонь с интервалом `rate` мс, пока палец на экране | Пистолет, Пулемёт, Лазер |
| `bomb` | взрыв радиуса `radius`, `fuse` — задержка, мс | Граната, Базука, Ядерка |
| `drop` | падает сверху | Наковальня |

`dmg` — урон за попадание, `force` — сила отлёта. Сейчас оружие на экране — это emoji из поля `icon`:
он рисуется в `weapons.js` (снаряды, около строки 176), в `fx.swing` (замах) и в карточках магазина (`main.js`, около строки 179).
Замена emoji на картинки — задача из [TEXTURES.md](TEXTURES.md).

### Эффекты (`fx.js`)

Частицы, кольца, слова-комиксы (БАМ!, ХРЯСЬ!), полетевшие к счётчику монеты, пыль, трещины и дырки в стене,
тряска, зум, вспышка, гильзы, дым, пузырь с фразой друга. Константы с префиксом `FX_`.

### Звук (`sfx.js`)

Синтез WebAudio без файлов. Работает, но звучит дёшево. Это первый кандидат на полировку.

### Загрузка

`index.html` показывает жёлтый экран «БЕЙ ДРУГА». `main.js` грузит `api/config` и `assets/manifest.json`,
затем только картинки текущего друга (`needs(i)`, `loadImages`, с повторами). Остальные друзья догружаются в фоне.
Так сделано потому, что у друзей на iPhone игра висела на сером экране.

### Синхронизация (`net.js`)

Удары и монеты копятся в localStorage и уходят пакетом раз в 5 с, при покупке и при скрытии вкладки.
У каждого пакета есть `seq`, сервер принимает его один раз (идемпотентность). Без сети игра продолжается.

## Сервер

- `server.ts`: node:http без зависимостей. Тело запроса до 4 КБ, раздаёт статику для локальной разработки
  (на проде статику отдаёт nginx), защищён от path traversal.
- `appstate.ts`: чистые функции — `verifyInitData` (HMAC по токену бота, срок 24 ч), `applySync`, `topData`, миграции базы.
- База — один JSON-файл. Запись раз в секунду, атомарная. Битую базу сервер отказывается открывать, а не обнуляет.

## Картинки

```
heads-src/<id>.png, <id>-hurt.png, <id>-ko.png    головы на маджента-фоне #FF00FF
body-src/naked.png, f1.png, f3.png                листы из 5 деталей: torso, arm, hand, thigh, shin
        │  .venv/bin/python scripts/assets.py
        ▼
app/assets/head-*.png, body-<sheet>-<part>.png, manifest.json
```

- Маджента вырезается в прозрачность, палитра квантуется до 96 цветов.
- Три головы друга кладутся на общий холст: один масштаб, низ шеи по центру и на одной высоте.
  В манифесте `[w, h, k]`, где `k` — во сколько раз холст шире обычной головы.
- Лист тела режется на 5 деталей по прозрачным промежуткам. Вторая рука и нога получаются зеркалом.
- Костюмы: `naked` (трусы) у всех по умолчанию. У друга с `outfit` в `config.ts` кнопка в правой панели
  переключает на его одежду. Сейчас одежда есть у Пешки (`f1`) и Боба (`f3`).

## Решения, которые не стоит пересматривать без причины

| Решение | Почему |
|---|---|
| Без сборщика и фреймворка | Игра маленькая, деплой — копирование файлов, нечему ломаться |
| Монеты считает клиент, сервер только ограничивает | Серверная симуляция физики — неделя работы ради защиты от друзей |
| Matter.js, а не свой движок | Рэгдолл с констрейнтами из коробки |
| Telegram SDK и шрифты локально | Блокировки в РФ |
| Один JSON-файл как база | 6–30 игроков, транзакции не нужны |
