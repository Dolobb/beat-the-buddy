# Beat the Buddy

Telegram HTML-виджет по локальной документации Bot API 10.4. Нужны Node 25 и Python 3.

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN` (не публикуйте файл).
3. Для новой установки: `npm i`. В подготовленном репозитории зависимости уже есть.
4. `npm start` собирает, проверяет размер и запускает long polling. Отправьте боту `/start`.

Проверки: `npm run build && npm run size`, затем `npm test`.
Откройте `dist/preview.html` в браузере: контейнер 360 px, локальная имитация покупок и начислений, демонстрационный лидерборд. Сервер для preview не нужен.

Друзей (ровно 6), оружие, фразы и баланс меняйте только в `config.ts`.
Необязательные лица: `faces/<id>.webp`, `.png` или `.jpg`, где `id` — из конфигурации.
Ориентир размера файла — до ~750 байт: весь data URL с base64 должен помещаться в ответ 1024 байта. Изображение — до 1024×1024. Иначе отображается буква имени.
После изменений пересоберите и перезапустите: новый HTML создаст новый shared-виджет при `/start`.
Старые сообщения сохраняют прежний HTML. Резервируйте `data.json`: там монеты, оружие и общий рейтинг.
Останавливайте через SIGINT/SIGTERM для сброса сохранения на диск.

В продакшене виджеты доступны только в личке с ботом. Группы и пересылку проверяют на [тестовом сервере Telegram](https://core.telegram.org/bots/webapps#using-bots-in-the-test-environment): отдельный тестовый аккаунт, бот и Bot API `/bot<TOKEN>/test/<method>` вместо обычного URL в `bot.ts`.
Лимиты: 4096 байт zlib-9 и 32768 сырых, 4 КБ localStorage на сообщение, ответы/состояние по 1024 байта. Звука нет. Вертикальный драг всегда забирает чат и отменяет стрельбу.
Синхронизация в фоне работает только в личке; preview не проверяет ограничения QuickJS и Telegram. Протокол дельт без идентификатора операции не обеспечивает exactly-once при потере ответа после начисления.

## Оружие

В конфиге 8 видов оружия, в виджете — сетка из 4 колонок. Новое оружие добавляется одной строкой в конец `weapons`, без правок виджета:
```ts
{ name: 'Новое', icon: '🔨', price: 3000, dmg: 6, radius: 70, force: 18, mode: 0, auto: 0 },
```
`dmg` — урон и монеты, `radius` — радиус попадания, `force` — сила импульса.
`mode: 0` бьёт в точке тапа, `mode: 1` запускает иконку-снаряд. `auto: 0` — одиночный удар,
иначе интервал автоогня в миллисекундах при удержании. При `force >= 20` — тряска и сильная вибрация.
Цена 700 показывается как `700`, 2000 — `2к`, 15000 — `15к`. Потолок дельты бот считает от максимального `dmg` и `HP`.
Порядок существующих записей сохраняйте: покупки хранятся битами по индексам. После добавления проверьте высоту сетки в preview и `npm run size`: лимит 4096 байт остаётся.

## Фразы

Добавьте другу поле `phrases: ['Первая фраза', 'Вторая фраза']`. Без поля используется общий массив `phrases`;
у Бло (`f2`, индекс 1) свой набор про долг. Бот отдаёт JSON по `p:<индекс друга>` и обрезает список с конца до 1024 байт UTF-8.
Тексты отсутствуют в `dist/widget.html`: виджет загружает их при старте и смене друга через очередь
«лицо → фразы → дельта», хранит только в памяти. До загрузки пузырь скрыт, после — показывается на 1200 мс и вписывается в canvas.
Preview получает те же наборы при сборке. Для обновления фраз в уже открытом виджете выберите друга заново или откройте виджет повторно после перезапуска бота.

## Лица из картинок

1. Положи головы на маджента-фоне `#FF00FF` в `faces-src/<id>.png`, где `<id>` совпадает с `id` друга в `config.ts`.
2. Один раз: `python3 -m venv .venv && .venv/bin/pip install pillow`.
3. `.venv/bin/python scripts/faces.py` вырежет фон, ужмёт до 32–56 px и положит `faces/<id>.webp` не больше 750 байт.

Бот читает лица при каждом запросе, перезапуск не нужен. Виджет кеширует лицо в `localStorage` сообщения, поэтому новое лицо увидишь после нового `/start`.
