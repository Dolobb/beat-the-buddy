# Beat the Buddy — инструкции для агента

Telegram Mini App: рэгдолл друга на Matter.js, оружие, монеты, общий рейтинг. Без сборщика и фреймворков.
Прочитай `docs/STATUS.md`, чтобы понять, что уже сделано, и выбери задачу из `docs/TEXTURES.md` или `docs/POLISH.md`.

## Жёсткие правила

1. **Работа только в своей ветке и через PR в `main`.** В `main` напрямую не пушить.
2. **Не выкладывать на сервер.** Доступа к проду у тебя нет, выкладывает владелец (Максим) после мерджа.
3. **Не трогать протокол и экономику без явной просьбы:** `appstate.ts`, `net.js`, формулу монет в `main.js` `damage()`, цены в `config.ts`.
   Сервер ограничивает монеты в пакете. Если клиент начнёт начислять больше лимита, пакеты отвергнутся и игроки потеряют прогресс.
4. **Порядок `appWeapons` в `config.ts` не менять.** Покупки хранятся по индексам. Новое оружие добавлять только в конец.
5. **Виджет заморожен:** `bot.ts`, `state.ts`, `widget/`, `scripts/build.ts`, `scripts/size.ts`, `faces*/` не трогать.
6. **Никаких секретов в репо:** `.env`, `data.json`, `appdata.json` в `.gitignore`. В репо лежат фото и имена друзей, поэтому репо приватный. Не выкладывай их наружу и не отправляй во внешние сервисы, кроме генератора картинок по задаче.
7. **Перед PR:** `npm test` зелёный, плюс глазами в браузере через `DEV=1 npm run app`. В PR приложи скриншот или гифку.
8. **Новых npm-зависимостей не добавлять** без согласования. Клиент — чистые ES-модули, всё вендорное лежит в `app/vendor/`.

## Карта

```
config.ts            друзья, оружие (appWeapons), фразы, APP_HP, APP_KO_BONUS, APP_COIN_MULT
server.ts            node:http на 127.0.0.1:8787: статика + /api/config, /api/sync, /api/top
appstate.ts          чистые функции состояния: проверка initData, applySync (лимиты монет, seq), рейтинг
app/index.html       весь UI и CSS (комикс-стиль, токены цвета в :root)
app/main.js          игровой цикл, рендер, комната, урон/монеты, KO, магазин, загрузка картинок
app/physics.js       рэгдолл: 10 частей, фикс-шаг 1/60, пружины позы, «кукловод», stagger после ударов
app/weapons.js       12 видов оружия: hand/melee/throw/gun/bomb/drop
app/fx.js            частицы, слова БАМ!, монеты, трещины, дырки, тряска, зум, вспышка
app/sfx.js           синтезированный WebAudio-звук (слабое место, см. POLISH)
app/net.js           очередь синхронизации с seq и localStorage
app/assets/          готовые PNG + manifest.json. Генерируется скриптом, руками не править
heads-src/ body-src/ исходники картинок на маджента-фоне
scripts/assets.py    исходники -> app/assets (вырезает мадженту, выравнивает головы по шее, режет тела)
e2e/                 e2e бэкенда: поднимает настоящий сервер с временной базой
deploy/              nginx и systemd для прода
```

## Команды

```sh
npm i
DEV=1 npm run app                       # http://127.0.0.1:8787/buddy/  (#hit #ko #friends #top #gun)
npm test                                # все тесты (node --test)
python3 -m venv .venv && .venv/bin/pip install pillow   # один раз
.venv/bin/python scripts/assets.py      # пересобрать app/assets после новых картинок
```

## Подводные камни

- **Физика на фикс-шаге 1000/60 с аккумулятором.** Переменный шаг давал «эпилепсию» рэгдолла. Не убирать.
- **Импульсы, возникшие во время шага, откладываются** до конца солвера (`pendingImpulses`), иначе солвер их стирает и отлёта нет.
- **Пружины позы и «кукловод» на время stagger ослабевают.** Если их не отпускать, удар гасится и голова стоит на месте.
- **Telegram SDK грузится локально** (`app/vendor/telegram-web-app.js`): `telegram.org` в РФ заблокирован.
- **Картинки грузятся лениво:** только текущий друг, остальные в фоне. Новая текстура должна попасть в `needs()`/`loadImages()` в `main.js`, иначе её не будет на первом кадре.
- **Головы:** три состояния (обычная, `-hurt` ниже 50% HP, `-ko`) на одном холсте, выровнены по шее. Новую голову класть во все три варианта.
